# Exercises and solutions

The exercises are at the end of each lesson in [`notebooks/`](../notebooks/),
under "Exercises". Each lesson also has "Check your understanding" questions
with the answer one click away.

Worked solutions to the exercises are in [`solutions/`](solutions/), one
notebook per lesson:

| Lesson | Solutions |
|---|---|
| 00 · What does a VNA measure? | [00_solutions.ipynb](solutions/00_solutions.ipynb) |
| 01 · Reflection coefficient and the Smith chart | [01_solutions.ipynb](solutions/01_solutions.ipynb) |
| 02 · Systematic errors | [02_solutions.ipynb](solutions/02_solutions.ipynb) |
| 03 · SOL calibration | [03_solutions.ipynb](solutions/03_solutions.ipynb) |
| 05 · Validation and measurement quality | [05_solutions.ipynb](solutions/05_solutions.ipynb) |

Try an exercise before opening its solution. The solution notebooks run on
their own and are executed by the test suite, so they stay correct when the
lessons change.

**For instructors.** The solutions are public. If you want to set graded
work, change the numbers (component values, cable lengths, which repetitions
are used) or use the open-ended parts of the exercises, such as explaining a
result or designing a validation rule.
